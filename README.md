# 💾 Шизо 95: Клинический синтезатор & Telegram Mini App

> **Шизо 95** — интерактивное ретро-приложение в эстетике Windows 95, объединяющее Telegram Mini App, FastAPI бэкенд, процедурный генератор абсурда и шизофазии, утилиту **DEFRAG.EXE (Дефрагментатор навязчивых мыслей)** и интерактивного ассистента **Доктор Скрепка**.

---

## 🖥️ Новые ключевые модули

### 1. 💾 Дефрагментатор навязчивых мыслей (`DEFRAG.EXE`)
- **Отдельное перетаскиваемое окно Windows 95:** Полнофункциональный оконный интерфейс с кнопками управления (`_`, `□`, `✕`), меню (`Файл`, `Действия`, `Кластеры`, `Справка`) и статусной строкой.
- **Canvas-сетка кластеров (512 блоков):**
  - 🟦 **Синие:** Связные мысли / Свободно (уплотнённые кластеры)
  - 🟥 **Красные:** Навязчивый бред / Фрагментировано
  - ⬜ **Белые:** Пустота / Не распределено
  - 🟩 **Зеленые:** Озарение / Чтение-Запись (сканирующая головка)
- **Симуляция и анимация (`requestAnimationFrame`):** Пошаговое вытеснение фрагментированных мыслей и уплотнение в непрерывный стек с динамическим прогресс-баром и статусами (*«Уплотнение сверхценных идей...»*, *«Очистка реверсивной логики...»*, *«Экранирование фольгой ГОСТ 1995...»*).
- **Процедурная озвучка HDD (Web Audio API):** Аутентичный хруст и треск шагового двигателя жесткого диска 1995 года без использования внешних аудиофайлов.

### 2. 🩺 Дискурсивный ассистент «Доктор Скрепка»
- **Персонаж со сложной SVG-анимацией:** Металлическая скрепка с врачебным лобным рефлектором (head mirror), зрачками, следящими за курсором, анимацией моргания и подпрыгивания на месте.
- **Интерактивные диалоги и всплывающий Speech Bubble:**
  - *«Похоже, вы пытаетесь скрыть мысли от спутника. Заземлить системный блок через батарею?»* → `[Да, заземлить]` / `[Игнорировать облучение]`
  - *«Вектор вашей шизофазии пересек границу дозволенного. Рекомендую вызвать искусственный дефицит внимания.»* → `[Принять рекомендации]` / `[Закрыть рот Скрепке]`
  - *«Обнаружен конфликт IRQ. Назначить 50 мг ассемблерных вставок?»* → `[Ввести внутривенно]` / `[Вызвать синий экран]`
- **Реакции системы:** Электростатические вспышки экрана, запуск дефрагментации на полной скорости, юмористический BSOD (синий экран смерти) и мутация мыслей.

### 3. 🎚️ Слайдер «Фаза обострения» и Zalgo-мутатор
- Регулировка уровня делирия от **0 (Ремиссия)** до **100 (Полный психоз 95)**.
- При повышении уровня текст мутирует в реальном времени: заикание слогов, искажение глифов, Zalgo diacritics (`Z̶̢̛a̷l̵g̴o̷`) и кибер-клинические теги тревоги (`[0xDEADBEEF]`, `[СБОЙ_РЕАЛЬНОСТИ]`).
- При критическом уровне Доктор Скрепка впадает в панику и требует немедленного запуска дефрагментатора.

### 4. 📚 Расширенная база цитат (`quotes.json`)
Более **75 авторских паттернов** по категориям:
- Псевдолатынь и античность;
- IT-деградация и деплой;
- Кибер-клиническая шизофазия;
- Схемотехнический делирий и BIOS;
- Бытовой сюрреализм и локальные новости;
- Миннесотский диалект и неожиданные иноязычные вставки.

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Запуск локального сервера (FastAPI + Telegram WebApp)
```bash
python main.py
```
Или через `uvicorn`:
```bash
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

Приложение откроется на [http://localhost:8000](http://localhost:8000).

### 3. Запуск Telegram-бота (при наличии токена BotFather)
1. Скопируйте `.env.example` в `.env`:
   ```bash
   cp .env.example .env
   ```
2. Укажите ваш `BOT_TOKEN` и публичный HTTPS URL (`WEBAPP_URL`, например через `ngrok http 8000`).
3. При старте `python main.py` Telegram-бот запустится автоматически в фоновом режиме.
