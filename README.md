# 💾 Шизо 95: Клинический синтезатор

Автономное кроссплатформенное ретро-приложение для процедурной генерации клинического бреда, технопсихоза и псевдолатыни с визуальным движком EarthBound и телеметрией энтропии Шеннона в аутентичной эстетике Windows 95.

---

## 🧠 Ключевые возможности

### 1. Интерфейс Windows 95 и эргономика
- **Свободная трансформация:** Настоящий Drag & Drop за заголовок (`.title-bar`) с ограничением по границам экрана (полная поддержка мыши и Touch API).
- **8-сторонняя растяжка (Resize):** Интерактивные ручки по периметру с системными курсорами и умным захватом указателя (Pointer Capture).
- **Ретро-контролы в шапке окна:**
  - `_` — **Window Shade:** Мгновенное схлопывание окна в компактную полоску заголовка.
  - `□` — **Maximize:** Разворачивание на весь рабочий стол с опцией восстановления исходной геометрии.
  - `░` — **Ghost Mode:** Винтажная полупрозрачность со сканлайнами и матричной сеткой.
  - `✕` — **Close:** Нативное закрытие процесса через системный мост (`pywebview.api.close()` на Desktop или `AndroidBridge.closeApp()` на мобильных устройствах).
- **Пиксельная типографика:** Интегрированный шрифт *Galmuri9* с аппаратным сглаживанием pixel-perfect (свободная рендеринг-поддержка латиницы, кириллицы и корейского хангыля).

### 2. Движок EarthBound Battle Background
- **SNES-рендеринг:** Генерация процедурных плазменных волн на `<canvas>` в оригинальном нативном разрешении (256 × 224) с аппаратным масштабированием.
- **Scanline Sine Warp:** Горизонтальный волновой сдвиг строк по математической формуле `x' = x + A * sin(k * y + ω * t)`.
- **Palette Cycling:** Четыре медитативные цветовые палитры (индиго-космос, изумрудный мох, бархатный пурпур, тёмный янтарь) с плавной RGB-интерполяцией.
- **Photosensitive Safe:** Встроенная защита от стробоскопических вспышек и резких перепадов яркости с сохранением плавной реактивности во время генерации.

### 3. Математический генератор шизофазии (CFG + Морфемный мутатор)
- **4 клинических профиля синтеза:**
  - **Атаксическая инкогеренция (Word Salad):** Синтаксический распад и бесконечные ассоциативные связи.
  - **Параноидный неологизм / Технопсихоз:** Процедурная сборка префиксов, корней и суффиксов на базе кибер-терминологии (например: *«гомперить», «субферритизация стека BIOS»*).
  - **Ритуальная латинская вербигерация:** Грамматически выверенная технократическая псевдолатынь.
  - **Олигофазический бытовой сюрреализм:** Загадочные хроники инженеров на хангыле и абсурдные бытовые идиомы.
- **Антидубликация:** Строгий кольцевой буфер истории, исключающий повторение тезисов и смысловых паттернов.

### 4. Реальное время и телеметрия
- **Информационная энтропия Шеннона:** Динамический расчёт сложности текста: `H(S) = −Σ P(ci) log2 P(ci)` [бит/символ].
- **Когерентность мышления:** Вывод флуктуаций стабильности сознания в процентах и замер частоты волны заднего фона (Hz).
- **Синтез аудио:** Встроенный 8-битный процедурный аудио-движок на Web Audio API для генерации арпеджио и лоу-фай кликов без внешних тяжеловесных ассетов.

## 🚀 Сборка и запуск

### 🐧 Desktop (Linux & Windows)
Приложение работает напрямую через легковесный нативный мост `pywebview`. Откройте терминал, установите зависимости и запустите ядро:
```bash
pip install -r requirements.txt
python main.py
```
*(Для Linux также предусмотрена однострочная сборка автономного AppImage — достаточно запустить `./build_linux.sh`)*.

### 📱 Офлайн для Android
Вся бизнес-логика выведена в HTML/JS ядро без серверов. Приложение оборачивается в легковесный Android WebView.
Готовые пакеты (`.apk`) собираются автоматически по коммитам в репозитории с помощью [build.yml](.github/workflows/build.yml). Развернуть локально можно через `android/native-webview/` в Android Studio.

### 🌐 Браузер (PWA)
Сконфигурировано как независимое веб-приложение. Имеет кэш Service Worker'а и манифест для установки прямо из браузера на любой ОС.
Откройте локально с монтированием папки ядра:
```bash
python -m http.server 8000 -d web
```
