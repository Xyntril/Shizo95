# 💾 Шизо 95 — Telegram Mini App

> **Шизо_95.exe** — интерактивный генератор абсурда, античной псевдолатыни, IT-деградации и шизофазии в аутентичной ретро-эстетике Windows 95 / 98.

---

## 🖥️ Особенности проекта

- **Стек бэкенда:** Python 3.10+ (FastAPI + aiogram 3.x + Uvicorn).
- **Стек фронтенда:** Чистый Vanilla JS + HTML5 + CSS3 + интеграция с официальным **Telegram WebApp SDK** (`telegram-web-app.js`).
- **Стилизация:** Аутентичный ретро-вид Windows 95/98 на базе библиотеки `98.css` с классической палитрой (`#008080`, `#c0c0c0`, `#000080`), 3D-рамками, пиксельной графикой и скроллбарами.
- **Звук и тактильность:** Встроенный ретро-синтезатор звуков щелчков и ошибок (Web Audio API) + тактильный виброотклик Telegram Haptic Feedback (`Telegram.WebApp.HapticFeedback`).
- **Двусторонняя связь с Telegram:**
  - Открытие через Inline-кнопку и Menu Button;
  - Отправка сгенерированного перла прямо в чат через `Telegram.WebApp.sendData()`;
  - Копирование в буфер обмена с визуальным уведомлением.

## 🚀 Быстрый старт

### 1. Установка зависимостей

Активируйте виртуальное окружение и установите библиотеки:

```bash
pip install -r requirements.txt
```

### 2. Настройка переменных окружения

Скопируйте файл конфигурации:

```bash
cp .env.example .env
```

Откройте файл `.env` и укажите:
- `BOT_TOKEN` — токен вашего Telegram-бота, полученный у [@BotFather](https://t.me/BotFather).
- `WEBAPP_URL` — публичный HTTPS-адрес вашего веб-приложения (см. шаг 3 ниже).
- `HOST` и `PORT` — хост и порт для запуска FastAPI (по умолчанию `0.0.0.0:8000`).

> ℹ️ *Если `BOT_TOKEN` не указан, сервер запустится в автономном веб-режиме, позволяя тестировать интерфейс в обычном браузере.*

## 🌐 Туннелирование для работы в Telegram (HTTPS)

Telegram Mini Apps требуют защищённого соединения **HTTPS**. Для локальной разработки используйте любой инструмент туннелирования:

### Вариант А: ngrok (рекомендуется)
```bash
ngrok http 8000
```
Скопируйте сгенерированный адрес (например, `https://abcd-12-34.ngrok-free.app`) и укажите его в `.env` в параметре `WEBAPP_URL`.

### Вариант Б: cloudflared (без регистрации)
```bash
cloudflared tunnel --url http://localhost:8000
```

### Вариант В: localtunnel
```bash
npx localtunnel --port 8000
```

## 🤖 Настройка бота в @BotFather

1. Перейдите к [@BotFather](https://t.me/BotFather) в Telegram.
2. Создайте бота командой `/newbot` и скопируйте полученный токен в `BOT_TOKEN` в `.env`.
3. *(Опционально)* Настройте кнопку меню бота для быстрого запуска WebApp:
   - Отправьте команду `/setmenubutton`.
   - Выберите созданного бота.
   - Введите текст кнопки: `⚡ Шизо 95`.
   - Отправьте ваш публичный HTTPS-URL (тот же, что и `WEBAPP_URL`).

## ▶️ Запуск приложения

Запустите сервер одной командой:

```bash
python main.py
```

Или напрямую через `uvicorn`:

```bash
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

После старта:
- В браузере откройте: [http://localhost:8000](http://localhost:8000) для предпросмотра интерфейса.
- В Telegram отправьте команду `/start` вашему боту и нажмите кнопку **«⚡ Запустить Шизо_95.exe»**.
